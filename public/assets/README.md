# Assets públicos

Coloca aquí recursos finales (GLTF, HDRI, audio, video) sin pasar por el bundler.

```
public/assets/
  models/     # casa.glb, palma.glb, props…
  hdri/       # cielo.hdr / .env
  audio/      # ambiente.mp3
  video/      # documental.mp4
  textures/   # PBR maps
```

El hito 1 usa geometría procedural; estas carpetas están listas para el reemplazo.
